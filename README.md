# TechSupport Pro - Enterprise Console

Sistema moderno de gerenciamento de chamados técnicos, construído com Vanilla JS e integrado com Supabase para persistência de dados em tempo real.

## 🚀 Funcionalidades

- **Dashboard Interativo**: Visualização rápida de chamados abertos, em atendimento e resolvidos.
- **Gestão de Chamados**: CRUD completo de tickets com prioridades e categorias.
- **Área Administrativa**: Controle de usuários, permissões, categorias e status do sistema.
- **Configurações de Usuário**: Preferências de aparência (Dark Mode) e notificações.
- **Relatórios**: Gráficos dinâmicos de distribuição de chamados por categoria e status.

## 🛠️ Tecnologias

- **Front-end**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Backend-as-a-Service**: Supabase (Auth, Database, RLS).
- **Icons**: Material Symbols Outlined.
- **Fonts**: Inter (Google Fonts).

## ⚙️ Configuração

1. Clone o repositório.
2. Crie um arquivo `.env` baseado no `.env.example`.
3. Insira suas credenciais do Supabase.
4. Execute o `schema.sql` no SQL Editor do seu projeto Supabase.
5. Abra o `index.html` em um servidor local (Live Server recomendado).
